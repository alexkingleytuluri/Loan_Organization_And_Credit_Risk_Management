# Loan Organization and Credit Risk Management System

A Python-based Loan Organization and Credit Risk Management System with Machine Learning-based credit risk assessment.

## Project Overview

This project aims to develop a centralized loan management platform that manages the complete loan lifecycle, from customer registration and loan applications to credit risk assessment, loan disbursement, repayment tracking, and collections.

Machine Learning will be used to estimate the credit risk of applicants and assist human decision-makers in the loan approval process.

## Key Features

- Customer registration and management
- Loan application management
- Machine Learning-based credit risk prediction
- Loan eligibility and underwriting support
- Loan disbursement tracking
- EMI and repayment management
- Overdue payment and collections tracking
- Portfolio analytics dashboard

## Technology Stack

**Backend:** Python, FastAPI

**Machine Learning:** Pandas, NumPy, Scikit-learn

**Database:** SQLite initially, MySQL later

**Frontend:** HTML, CSS, JavaScript

**Version Control:** Git and GitHub
